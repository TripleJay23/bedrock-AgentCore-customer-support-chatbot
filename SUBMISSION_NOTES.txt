Customer Support Chatbot — Submission Notes

This submission uses the updated Amazon Bedrock AgentCore version of the
Udacity project starter.

The current implementation uses:
- Amazon Bedrock AgentCore managed harness
- AgentCore Gateway
- AWS Lambda create_bug_report tool
- Amazon DynamoDB
- Amazon Bedrock Evaluations
- Amazon Bedrock Guardrails

Some rubric text still uses terminology from the earlier Bedrock Flows
version of the project. In the current AgentCore starter:

- harness-tests.json is the automated chatbot test suite corresponding to
  the older rubric reference to flow-tests.json.
- generate-eval-dataset.py invokes the AgentCore harness and produces the
  Bedrock Evaluations JSONL dataset.
- system_prompt.txt implements routing, FAQ grounding, bug-report
  information collection, and human handoff behavior.
